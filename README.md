# File-Organizer


📂 File Organizer Script

This project automatically organizes files in a folder based on their file types.
It helps keep your desktop or download folder clean by moving files into categories like Images, Videos, Documents, etc.


---

📌 Features

Automatically detects file types

Moves files into categorized folders

Simple and easy-to-use Python script

Works for any directory



---

🚀 How to Use

1. Download or clone this project


2. Place the Python script inside the folder you want to organize


3. Run the script using:

python file_organizer.py


4. The folder will be organized automatically




---

🗂 Categories Created

The script organizes files into:

Images

Videos

Documents

Audio

Archives

Others



---

🧪 Example

Before running → All files are mixed
After running → Neat folders are created automatically
